Changelog

Everything that changed in SteamLite, newest first. Pulled straight from the GitHub releases.

10.1.5

Stable2026-10-23

The Non-Steam page.

  • New Non-Steam button in the dock: it lists the games that are running right now and are not from Steam, spotted from the running programs, including games with an anti-cheat.
  • Pictures and details are found for each game: first from the Steam store, then Wikipedia, then the program's own icon.
  • Click a game for a temporary game page. It is not kept in your library unless you press Add to library.
  • Games from a store's launcher (Rockstar, Epic, GOG, EA, Ubisoft, Battle.net, Riot, Xbox) say Open launcher instead of Play, and play time is still counted.
  • Earlier in 10.1.x: themes you download, collections, an offline mode, a verified tick, an About page with the community links, and fixes.

10.0.3

Stable2026-10-21

Profiles, a setup page for new profiles, and a fix for games with an anti-cheat.

  • Profiles: switch between Steam accounts, or add another one with Sign in with Steam, from your picture in the title bar. Each profile keeps its own sign-in, so you can switch back and forth without signing in again.
  • A new profile opens on a full-screen page to set up its SteamLite account: message notifications, Windows notifications, message sound, friend requests and streak reminders.
  • Games with an anti-cheat (Easy Anti-Cheat, BattlEye) are no longer counted as closed when their launcher quits.
  • Sign out now really signs the profile out.
